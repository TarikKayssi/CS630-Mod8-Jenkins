Technical Instructions

This week’s assignment is to take a sample python program with a test and build continuous integration around it, specifically using Jenkins. The files you need are in the ~/CS630/8-2 directory in codio. You can also find a public repository to fork in GitHub at:
	https://github.com/heusserm/CS630

Test Programs

The program is written in python; you will be testing the API. The code library is triangle.py; the actual API is stand_up_triangle_api.py which sets up the API running on port 5082. test program is test_stood_up_triangle.py. To run the test program, you’d do something like this:

In one tab:
	cd ~/CS630/8-2
	python3 stand_up_triangle_api.py

In another:
	cd ~/CS630/8-2
	pytest

Go back to the first tab and press control-c to cancel the API.

Starting Jenkins

Jenkins is installed in your codio. To start it, go to the terminal, and type this:

sudo systemctl start jenkins

That command will launch Jenkins in the background. Wait a few seconds. Then, to check the status of your launched Jenkins, type:

sudo systemctl status jenkins

If Jenkins is running, it will be a server on your own computer (localhost). To find Jenkins, launch a web browser and direct it to: 

http://localhost:8080

When you launch Jenkins, it will ask you for a code. You can find that code by running this command on the terminal:

sudo cat /var/lib/jenkins/secrets/initialAdminPassword 
 
That will give you a complex codeword. You can highlight it and right click and copy it into your paste buffer, then paste it into a browser.

After that, you can create an admin user or just skip it, using username admin and the password from terminal.

There are at least two ways you could configure Jenkins: 

1) You could store the files in git in a public repository, then configure git to run a new build every time.

2) You could configure GIT to run periodically (every 15 minutes? Hour?) and, perhaps, check if any files have changed on the file system. This can be done with the FSTrigger Plugin. ( https://plugins.jenkins.io/fstrigger/ )
